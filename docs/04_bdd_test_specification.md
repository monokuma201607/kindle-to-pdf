## 2. フィーチャーファイル

### Feature: Web UIからのキャプチャ操作

```gherkin
Feature: Web UIからのキャプチャ操作
  ユーザーはWeb UIを通じてKindle画面をキャプチャし、
  PDFファイルとして保存できる。

  Background:
    Given Web UIが起動している
    And Kindle for PCが起動している

  Scenario: Kindleウィンドウの自動検出
    When ユーザーがUIを開く
    Then Kindleウィンドウが検出済みと表示される

  Scenario: 自動モードでのキャプチャ開始
    Given Kindleウィンドウが検出されている
    And 自動モードが選択されている
    When ユーザーが開始ボタンをクリックする
    Then キャプチャが開始される
    And 進捗バーが更新される

  Scenario: ページ数指定モードでのキャプチャ
    Given Kindleウィンドウが検出されている
    And ページ数指定モードで10ページが入力されている
    When ユーザーが開始ボタンをクリックする
    Then 10ページのキャプチャが実行される
    And PDFファイルが生成される

  Scenario: キャプチャの中断
    Given キャプチャが実行中である
    When ユーザーが停止ボタンをクリックする
    Then キャプチャが中断される
    And キャプチャ済みのページでPDFが生成される

  Scenario: 進捗のリアルタイム表示
    Given キャプチャが実行中である
    When 1ページのキャプチャが完了する
    Then 進捗バーが更新される
    And プレビュー画像が更新される

  Scenario: 設定の変更
    Given 設定モーダルが開いている
    When ユーザーがキャプチャ間隔を2.0秒に変更する
    And 保存ボタンをクリックする
    Then 設定が保存される
    And 次回キャプチャに反映される

  Scenario: エラー発生時の表示
    Given Kindleウィンドウが閉じられている
    When ユーザーが開始ボタンをクリックする
    Then エラーメッセージが表示される
    And 「Kindleを起動してください」と表示される
```

---

## 3. ステップ定義概要

| ステップ | 実装方法 |
|---------|---------|
| Web UIが起動している | Flaskテストクライアント使用 |
| 開始ボタンをクリック | API POST /api/capture/start を呼び出し |
| 進捗バーが更新される | WebSocketイベントを検証 |
| PDFが生成される | ファイル存在確認 |

---

## 4. テストデータ

| データ | 内容 |
|--------|------|
| モックKindleウィンドウ | win32guiをモック化 |

| 期待PDF | 検証用PDFファイル |

## 2. フィーチャーファイル

### Feature: GUIからのキャプチャ操作

```gherkin
Feature: GUIからのキャプチャ操作
  ユーザーはデスクトップアプリを通じてKindle画面をキャプチャし、
  PDFファイルとして保存できる。

  Background:
    Given アプリケーションが起動している
    And Kindle for PCが起動している

  Scenario: Kindleウィンドウの自動検出
    When ユーザーがアプリを起動する
    Then ステータスラベルに「検出済み」と表示される
    And 書籍タイトルが検出される

  Scenario: 自動モードでのキャプチャ開始
    Given Kindleウィンドウが検出されている
    And 「自動」ラジオボタンが選択されている
    When ユーザーが開始ボタンをクリックする
    Then キャプチャ準備のカウントダウンが始まる
    And キャプチャ処理が実行される
    And 進捗バーが更新される

  Scenario: ページ数指定モードでのキャプチャ
    Given Kindleウィンドウが検出されている
    And 「ページ数指定」ラジオボタンを選択する
    And ページ数入力欄に"10"を入力する
    When ユーザーが開始ボタンをクリックする
    Then 10ページのキャプチャが実行される
    And PDFファイルが生成される

  Scenario: キャプチャの中断
    Given キャプチャが実行中である
    When ユーザーが停止ボタンをクリックする
    Then キャプチャが安全に停止する
    And ここまでのページでPDFが生成される

  Scenario: クロップ調整（黒帯除去）
    Given アプリケーションが起動している
    When ユーザーがクロップ調整ボタンをクリックする
    Then クロップ調整ダイアログが表示される
    And プレビュー画像が表示される
    When スライダーを操作する
    Then プレビュー画像がリアルタイムに更新される

  Scenario: 目次からの開始
    Given Kindleウィンドウが検出されている
    When ユーザーが「目次から開始」ボタンをクリックする
    Then 目次解析が実行される
    And 目次確認ダイアログが表示される
    When ユーザーが章情報を確認して開始する
    Then 目次情報付きでキャプチャが開始される
```

## 3. ステップ定義概要

| ステップ | 実装方法 |
|---------|---------|
| アプリケーションが起動している | `KindleCaptureApp` インスタンス化 |
| 開始ボタンをクリック | `app.start_btn.invoke()` または `command` 実行 |
| 進捗バーが更新される | `progress_bar.get()` の値を確認 |
| PDFが生成される | `pathlib.Path.exists()` 確認 |

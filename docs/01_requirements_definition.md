---

## 1. 概要

### 1.1 目的
Kindle for PCで表示されている書籍の画面をキャプチャし、複数ページを結合してPDFファイルとして保存するためのGUIアプリケーションを開発する。

### 1.2 背景
- 現在のCLI版は技術者以外には使いづらい
- 視覚的な進捗確認ができない
- 設定変更にコマンドライン引数の知識が必要

### 1.3 スコープ

| 対象 | 内容 |
|------|------|
| **In Scope** | Windows向けデスクトップアプリ(CustomTkinter)、リアルタイム進捗表示、設定画面、目次解析、クロップ調整 |
| **Out of Scope** | macOS/Linux対応、クラウド連携 |

---

## 2. ステークホルダー

| ステークホルダー | 役割 | 関心事 |
|-----------------|------|--------|
| エンドユーザー | 書籍所有者 | 簡単な操作、確実な動作、きれいなPDF生成 |
| 開発者 | 保守担当 | コード品質、拡張性 |

---

## 3. ユーザー要求

### 3.1 機能要求

| ID | 要求 | 優先度 |
|----|------|--------|
| UR-001 | GUIからキャプチャを開始・停止できる | 必須 |
| UR-002 | キャプチャの進捗をリアルタイムで確認できる | 必須 |
| UR-003 | キャプチャ間隔、自動停止ページ数などの設定を変更できる | 必須 |
| UR-004 | 書籍タイトルを自動検出し、出力ファイル名として提案する | 必須 |
| UR-005 | 自動モード（最後まで）とページ数指定モードを選択できる | 必須 |
| UR-006 | 不要な余白（黒帯・メニューバーなど）を除去するためのクロップ調整ができる | 必須 |
| UR-007 | 目次ページをOCR解析し、PDFにしおり（ブックマーク）を付与できる | 必須 |
| UR-008 | ページめくり方向（右開き/左開き）を指定し、PDFに反映できる | 必須 |

### 3.2 非機能要求

| ID | 要求 | 優先度 |
|----|------|--------|
| NFR-001 | 起動時間は3秒以内 | 必須 |
| NFR-002 | モダンで直感的なUI (CustomTkinter) | 必須 |
| NFR-003 | Windows 10/11で動作 | 必須 |
| NFR-004 | キャプチャ中のメモリリークがないこと | 必須 |

---

## 4. 制約条件

| 項目 | 制約 |
|------|------|
| 開発言語 | Python 3.8+ |
| UIフレームワーク | Desktop (CustomTkinter) |
| 対応OS | Windows 10/11 |
| 依存ライブラリ | kindle_capture, tesseract-ocr (目次解析用) |

---

## 5. 前提条件

- Kindle for PCがインストールされていること
- Python 3.8以上がインストールされていること
- ユーザーが合法的に所有する書籍のみを対象とすること
